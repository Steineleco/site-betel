# BETEL - Troca de Óleo

Site institucional da BETEL Troca de Óleo.

## Estrutura
- `index.html` — página principal
- `assets/css/style.css` — estilos personalizados
- `assets/js/script.js` — scripts
- `assets/img/` — imagens (logo, motor, água, favicon)

## Como rodar localmente
Abra o `index.html` no navegador.

## Como publicar
1. Suba para o GitHub
2. Conecte na Vercel (deploy automático)
